# CryftNet Whitepaper (GitHub edition)

This repo contains the CryftNet (Cryft Network) whitepaper in a **diff-friendly Markdown** format, suitable for GitHub version control.

## Files

- `docs/whitepaper.md` — primary source (Markdown)
- `docs/whitepaper-v1.5.pdf` — reference PDF snapshot (v1.5, 2026-01-02)

## Notes on formatting

- Headings are numbered to preserve the paper’s structure.
- Concept diagrams are rendered as Mermaid flowcharts for easy editing and review.
- A short “optional overlay mesh transport” note was added (Nebula as a **reference** implementation) without making it consensus-critical.
